# 来年度の就職活動に向けて

ゲームクリエイター科向けの、全15枚のWebスライドです。外部ライブラリ・画像を使わず、オフラインでも開けます。

## 起動方法

`index.html` をブラウザで開いてください。教室ではフルスクリーンボタン、またはブラウザの全画面機能を使うと見やすくなります。

## 操作方法

- `→` / `Space` / `PageDown` / 画面クリック：次へ
- `←` / `PageUp`：前へ
- `Home` / `End`：最初 / 最後
- 画面下部の矢印・全画面ボタンも利用できます。スマートフォンでは左右スワイプに対応します。

## ファイル構成

- `index.html`：15枚の内容と操作ボタン
- `style.css`：16:9のレイアウトとデザイン
- `script.js`：表示調整、移動、進行表示、全画面操作
